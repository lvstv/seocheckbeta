# Changelog

## [0.1.0] — 2026-11-20

Первая рабочая версия проекта.

### Добавлено
- Одностраничное приложение на чистых HTML, CSS и JavaScript.
- Навигация по 16 тематическим разделам технического SEO-аудита.
- Подробный стартовый раздел «Индексация и доступность сайта».
- Статусы проверок: не проверено, OK, ошибка, внимание, не применимо.
- Общий прогресс выполнения.
- Поиск по проверкам внутри выбранного раздела.
- Локальное сохранение отметок в браузере.
- Подготовлена структура для публикации на GitHub Pages.

### Ограничения
- Данные не синхронизируются между браузерами и устройствами.
- Разделы 2–16 пока содержат начальные пункты и будут детализированы в следующих версиях.
- Нет экспорта отчёта.

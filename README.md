# SEO Technical Audit Toolkit

**Версия:** 0.1.0  
**Стек:** HTML + CSS + JavaScript без фреймворков и сборщиков.  
**Хостинг:** GitHub Pages.

## Состав проекта

- `index.html` — разметка приложения.
- `styles.css` — оформление.
- `app.js` — логика интерфейса, статусы и локальное сохранение.
- `checklist.json` — содержимое чек-листа, отдельно от интерфейса.
- `CHANGELOG.md` — история версий.

## Запуск локально

Из-за загрузки `checklist.json` через `fetch()` не открывайте `index.html` двойным щелчком (`file://`). Запустите простой локальный сервер из папки проекта:

### Python
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`.

Либо используйте расширение Live Server в VS Code.

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub.
2. Загрузите в корень репозитория все файлы проекта.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем сохраните.
6. Дождитесь публикации и откройте выданный GitHub Pages URL.

## Важное ограничение v0.1.0

Отметки сохраняются в `localStorage` браузера. Они доступны только в том же браузере и на том же устройстве. Пока нет синхронизации между устройствами, учётных записей и совместной работы.

## Обновление проекта

Каждый релиз сопровождается обновлением номера версии и `CHANGELOG.md`. Перед заменой файлов сохраните копию текущей папки или создайте commit в Git.
